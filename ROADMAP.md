# Roadmap

This roadmap captures the intended direction of the project from the current public draft toward a more fully specified and externally validated framework.

## Current release: v0.1.0
- Public repository and working draft
- Reproducible framework + evidence
- Reversible fingerprint ↔ DNA ↔ 2-D walk implementation
- Initial proposal and testable hypotheses

## Planned: v0.2.0
- Real genome analysis for H1, H2, H3
- Evaluation of sequence classes under Chargaff parity rules
- Controls for length, GC content, and composition-preserving shuffles
- Additional statistical baselines and comparisons

## Planned: v0.3.0
- Formal definitions for D_min and D_path
- Better bridge documentation and refinement
- Extension to additional walk rules and representations
- Cleaner formal distinction between sequence-level and endpoint-level information

## Planned: v0.4.0
- Community review and issue-driven refinements
- Better reproducibility and provenance
- Expanded tests and evidence generation
- Formal public specification for the framework

## Planned: v1.0.0
- Publication-ready summary and theory writeup
- Stable version of the framework and analysis pipeline
- Full final specification of accepted rules and definitions
- Peer-reviewed or preprint-level publication packaging

## Open questions
- Which walk rule is canonical?
- Should the framework favor D_path or D_min in formal definitions?
- What is the best set of genome datasets for testing H1-H3?
- Is a 3-D or higher-dimensional model necessary or useful?
